# 📓 Jupyter Notebooks (Programming Fundamentals)

Original interactive laboratory exercises covering early Python fundamentals, control flow, functions, and collections.

---

## 📑 Contents

- **`Lab_3.ipynb`**: Basic Python syntax, variables, expressions, and conditional statements.
- **`Lab_4.ipynb`**: Iteration, while/for loops, and numeric pattern generation.
- **`Lab_5.ipynb`**: Functions, parameter passing, return values, and scope.
- **`Lab_6.ipynb`**: Strings, list manipulation, indexing, and slicing.
- **`Lab_7.ipynb`**: Dictionaries, sets, and key-value mapping exercises.
